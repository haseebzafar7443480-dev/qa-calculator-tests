# Calculator Test Suite

A beginner QA project: automated tests written with Python and pytest for a simple calculator.

## What is tested
- Normal cases (add, subtract, multiply, divide)
- Edge cases (negative numbers, zero)
- Error handling (division by zero)
- Multiple inputs using parametrized tests

## How to run
```
pip install pytest
pytest -v
```

## What I learned
- Writing test cases and assertions
- Testing expected errors
- Parametrized testing
- Using Git and GitHub
